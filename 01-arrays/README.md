# Unit I — Arrays, Searching, Sorting

## Problems

| Problem | File | Approach | Time | Space |
|---|---|---|---|---|
| Linear Search | `linear_search.cpp` | | O(n) | O(1) |
| Binary Search | `binary_search.cpp` | | O(log n) | O(1) |
| Selection Sort | `selection_sort.cpp` | | O(n²) | O(1) |
| Bubble Sort | `bubble_sort.cpp` | | O(n²) worst / Ω(n) best | O(1) |
| Insertion Sort | `insertion_sort.cpp` | | | |
| Array insert/delete | `array_ops.cpp` | | O(n) worst / O(1) at end | O(1) |

## Notes to self
- Binary search only works on sorted data.
- Array insertion/deletion complexity depends on position (front/mid = O(n), end = O(1)).
