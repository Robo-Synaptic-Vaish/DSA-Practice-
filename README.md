## Concept Notes (quick reference)

| Concept | Key takeaway |
|---|---|
| Big O / Omega / Theta | O = worst case, Ω = best case, Θ = when both match |
| Linear Search | O(n) |
| Binary Search | O(log n) — requires sorted data |
| Array access | O(1) — direct address calc |
| Array insert/delete (front/mid) | O(n) — shifting required |
| Array insert/delete (end) | O(1) — no shifting |
| Selection Sort | O(n²) best & worst — no early-stop |
| Bubble Sort | O(n²) worst, Ω(n) best — stops early if no swaps |
